## How to discuss a project

The most useful starting point is a description of **what players or server staff should be able to do**, rather than only a list of menus or commands.

When contacting us, consider including:

1. **Project goal:** What should the system accomplish?
2. **Gameplay experience:** How should players interact with it from start to finish?
3. **Server environment:** Your FiveM framework and relevant dependencies, if known.
4. **Essential requirements:** What must be included, and what is optional?
5. **Existing integrations:** Inventory, targeting, database, UI, or other systems the resource would need to work with.
6. **References:** Screenshots or examples that communicate the intended experience, without sending private or unauthorized files.

Do not post server credentials, license keys, payment information, protected code, or customer data in public channels.

## Project evaluation

A request may require discussion of gameplay scope, technical dependencies, implementation constraints, delivery expectations, and pricing **before any work is agreed**.

Custom development availability, quotations, project acceptance, schedules, deliverables, and commercial terms are **not established by this page**. They must be explicitly confirmed for each accepted project.

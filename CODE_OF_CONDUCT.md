# ToneCustoms Community Guidelines

Welcome to the **ToneCustoms GitHub community**.

This repository is the official home for ToneCustoms documentation, announcements, and discussions. We're here to exchange ideas, ask useful questions, and keep information accessible to the FiveM community.

These guidelines apply to conversations, issues, pull requests, and other contributions made in this GitHub repository.

## Our Expectations

### 1. Respect everyone

Treat other community members with courtesy. Harassment, threats, hateful remarks, discriminatory language, and personal attacks are not welcome.

Disagreeing with an idea is fine. Targeting the person behind it is not.

### 2. Keep discussions relevant

Use the right space for your post:

- **Announcements:** Official updates from ToneCustoms maintainers.
- **General:** Community conversations related to ToneCustoms.
- **Ideas:** Suggestions and constructive feedback.
- **Polls:** Community opinions and voting.
- **Q&A:** Questions and answers.
- **Show and tell:** Publicly shareable work and community showcases.
- **Issues:** Corrections, broken links, and improvements to documentation.
- **Pull requests:** Proposed documentation changes.

Please avoid spam, unrelated promotion, repeated posts, and misleading information.

### 3. Share constructive feedback

Be specific and respectful when suggesting changes. Describe the problem, explain why it matters, and propose improvements when possible.

Ideas and feedback are welcome, but suggestions are not promises of new features or changes.

### 4. Protect privacy and security

Do not post private information, credentials, access tokens, license keys, database details, or confidential code.

Do not share another person's personal information without permission.

If you find a security concern, follow the [Security Policy](SECURITY.md) and report it privately rather than publishing sensitive details.

### 5. Respect ownership and intellectual property

Only share content you have permission to distribute. Do not post leaked, stolen, or unauthorized resources. This GitHub repository is for **documentation**, not for distributing private ToneCustoms resource files.

### 6. Follow GitHub's platform rules

All activity must also follow [GitHub's Community Guidelines](https://docs.github.com/en/site-policy/github-terms/github-community-guidelines) and applicable terms.

## Moderation

Repository maintainers may edit labels, move or close discussions, hide or remove inappropriate content where GitHub permits, and restrict participation when necessary to protect the community.

Decisions are based on relevance, safety, conduct, and the goals of this documentation community.

## Reporting a Concern

For problematic GitHub content, use GitHub's available reporting tools or contact repository maintainers through an appropriate private channel.

For general ToneCustoms community help, visit the [official ToneCustoms Discord](https://discord.gg/JdZ7NTG5KF). Avoid posting sensitive incident details publicly.

For security vulnerabilities, follow [SECURITY.md](SECURITY.md).

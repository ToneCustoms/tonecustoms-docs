## Before installation

1. Obtain the resource from the official delivery method indicated by your purchase.
2. Read the product's dependency and folder structure instructions.
3. Install any supported required dependencies.
4. Follow item registration and `server.cfg` steps **specific to the product**.
5. Only edit files explicitly designated as configuration files, such as `config.lua`.

## Need help?

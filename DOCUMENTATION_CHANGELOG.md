# ToneCustoms Documentation Changelog

This page tracks material **changes to public guides and documentation**. It is **not** a script release log. Product versions and customer-facing software releases are recorded separately on the appropriate product changelog.

## October 24, 2026 — Documentation organization and customer guides

- Reorganized the main documentation into About, Products, Installation, Updates, Support and Policies.
- Added a dedicated **Meet Tone** developer introduction to the About page.
- Added and linked a Gun Jam customer installation and configuration guide.
- Added dedicated Gun Jam troubleshooting and release-history pages, without inventing a customer release version.
- Improved the reusable product documentation template.
- Clarified customer support and free released-update wording.
- Added an FAQ, framework compatibility guide, purchase/delivery guide, update guide, and contact/feedback directory.
- Introduced this documentation-specific changelog.

**Policy note:** Customer-facing documentation describes ToneCustoms' intended commercial approach; approved checkout terms, platform rules and applicable law still govern purchases.

## Keeping this history accurate

When updating this page, record:
- Date of publication
- Which documentation pages changed
- What changed for readers
- Whether any product's **actual** customer-facing release information changed (if so, link to that separate release history)

Do not add fictional features, unapproved policies, unverified public releases or private source content.

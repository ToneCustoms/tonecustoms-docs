## Active customer reports

Browse [open support tickets](https://github.com/ToneCustoms/tonecustoms-docs/issues?q=is%3Aissue+is%3Aopen+label%3Asupport) for ongoing reports. An open ticket is **not automatically a confirmed product defect**.

Browse [closed support tickets](https://github.com/ToneCustoms/tonecustoms-docs/issues?q=is%3Aissue+is%3Aclosed+label%3Asupport) for previous resolutions. A closed ticket is not necessarily a product update.

## Publishing a confirmed issue

Once an issue is verified, ToneCustoms can add a concise entry with:

- **Affected resource and versions:** Only versions verified to be impacted.
- **Symptoms:** What customers experience.
- **Status:** Investigating, workaround available, or fixed.
- **Workaround or resolution:** Verified steps only.
- **Tracking issue:** A link to the corresponding public GitHub issue.
- **Fixed version or date:** Only when a fix is actually released.

Avoid posting customer details, private source code, credentials, or unverified fixes.

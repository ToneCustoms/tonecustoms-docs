# ToneCustoms — Publication & Release Checklist

**Internal editorial workflow, published for transparency.** This checklist does not promise particular commercial features or entitlements.

## Product record

- [ ] Product name and purpose accurately described
- [ ] Working features individually verified
- [ ] Planned features separated from working features
- [ ] Framework and dependency compatibility tested and stated accurately
- [ ] Installation and configuration instructions match the approved build
- [ ] Clear images or video demonstrate actual behavior
- [ ] Known issues and limitations recorded
- [ ] Source code, passwords, tokens and proprietary assets remain private

## Quality gate

- [ ] In-game acceptance criteria passed
- [ ] Previous blocking bugs addressed or disclosed
- [ ] Approved version/tag assigned **after** validation
- [ ] Release notes reviewed
- [ ] Rollback path or recovery notes available where applicable
- [ ] Product availability confirmed before linking to a store listing

## Customer-facing gate

- [ ] License conditions approved for this particular product
- [ ] Delivery method confirmed
- [ ] Price and checkout terms confirmed at Tebex
- [ ] Update entitlements identified (if offered)
- [ ] Support coverage identified (if offered)
- [ ] Refund conditions consistent with applicable law and checkout terms
- [ ] Screenshots and descriptions are accurate, not speculative

## Asset-specific gate

- [ ] Custom inventory PNG is 100×100 pixels
- [ ] Genuine transparency; no baked checkerboard or white rectangle
- [ ] Complete, centered subject with no missing sections or adjacent-object artifacts
- [ ] Correct inventory filename
- [ ] Tested at actual inventory display size
- [ ] Owner approval recorded

## Owner sign-off

A feature or item should not be marked **Released** merely because code was committed, an image was generated, or a demonstration was recorded.

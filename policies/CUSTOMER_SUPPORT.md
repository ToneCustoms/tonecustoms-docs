# ToneCustoms — Customer Support

**Official customer support information**

ToneCustoms offers **free installation, configuration, and product issue assistance** for customers who purchased its scripts. Support remains available through official channels, but this is not a promise of immediate or around-the-clock responses.

## Where to contact us

| Reason | Channel |
| --- | --- |
| Help installing a purchased resource | [ToneCustoms GitHub Support](https://github.com/ToneCustoms/tonecustoms-docs/issues/new/choose) |
| Configuration help | [ToneCustoms GitHub Support](https://github.com/ToneCustoms/tonecustoms-docs/issues/new/choose) |
| Report a product bug | [ToneCustoms GitHub Support](https://github.com/ToneCustoms/tonecustoms-docs/issues/new/choose) |
| Purchase or entitlement question | Use the original Tebex order-support route for billing, delivery, and entitlement cases |
| Incorrect public documentation | [GitHub documentation issues](https://github.com/ToneCustoms/tonecustoms-docs/issues/new/choose) |
| Sensitive vulnerability | [Security disclosure instructions](../SECURITY.md) |

## Information to include

Give the resource name, the framework/inventory setup, what happened, the result you expected, and relevant screenshots or redacted console errors. Include the version **only if known**. When purchase verification is necessary, use the original private Tebex order-support thread.

GitHub support issues are public and require a GitHub account. Do not post passwords, payment details, license keys, webhooks, private source code, or other sensitive information in public issues.

## What's included

- Guidance for initial installation and dependency setup
- Help using the designated configuration files
- Assistance investigating errors associated with the purchased resource
- Guidance on accessing updates when released

**Separate work:** Commissioned custom features, reworking protected source, unrelated server repairs and third-party resource development are not automatically included with a product purchase. Any separate work should be discussed and agreed on before it begins.

**Target initial response:** Within 24–48 hours, depending on availability and ticket volume. This is not a guaranteed response or resolution deadline, and support is not staffed 24/7. Requests submitted outside staffed hours are reviewed during the next support period.

## Customer conduct and ticket rules

- Use the appropriate GitHub issue form and provide clear, relevant troubleshooting details.
- Keep discussions respectful; harassment, threats, discriminatory language, spam and deliberate false reports are not acceptable.
- Do not create duplicate issues to demand priority. Add relevant updates to the existing ticket.
- Do not publicly share license keys, credentials, private source code, customer data, payment details or order information.
- Keep billing, refunds and order-verification details in the original private Tebex support route.
- Support covers ToneCustoms products and their documented integrations; unrelated server administration or custom development requires separate agreement.
- ToneCustoms may moderate abusive public issue content and close requests that are duplicates, outside scope or resolved. Legitimate consumer rights and platform obligations remain unaffected.

For collaboration-specific conduct and licensing rules, see [Partnerships & Collaborations](../PARTNERSHIPS.md).

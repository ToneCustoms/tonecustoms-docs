# ToneCustoms — Privacy & Data Handling

**Status: Working outline, NOT an approved privacy notice.**

This document identifies the disclosures needed before publishing a definitive ToneCustoms privacy policy. **It does not claim that a specific collection, storage, transfer, or deletion practice is already in place.**

## Practices to verify

| Area | Questions to document |
| --- | --- |
| Store / checkout | Which business/payment details are processed by Tebex and which details ToneCustoms receives? |
| Discord / bots | What user IDs, messages, role information, logs or interaction events are collected? |
| Licensing | Is any license or server identifier retained? If so, for what purpose and duration? |
| Support | Are tickets, screenshots, logs, email addresses, or attachments stored? For how long? |
| Analytics | Are site, store or script usage events collected? |
| Data sharing | Which service providers process information and under which terms? |
| Rights and contact | How can customers request information, correction, or deletion when applicable? |
| Security | Who can access records, what safeguards apply, and how are incidents handled? |
| Retention | Define periods or objective retention criteria for each category of data |

## Customer safety in the meantime

Never publish passwords, API keys, webhook URLs, private license keys, payment information or personal server access details in public GitHub issues or Discussions.

For the checkout privacy notices and payment processing terms, refer to the actual provider's terms presented during purchase.

**Before publishing a binding privacy notice, verify actual data flows and applicable privacy requirements.**

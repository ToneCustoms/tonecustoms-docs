# ToneCustoms — Licensing Framework

**Status: Proposed policy draft — not yet approved commercial terms.**

ToneCustoms intends to keep proprietary script source code and custom artwork private unless an explicit license or distribution arrangement authorizes access.

## Topics to finalize

| Topic | Proposed direction — **subject to approval** |
| --- | --- |
| License grant | Define a clear scope of usage for each purchased resource |
| Server allowance | Specify whether a license covers one server, multiple servers, or a named organization |
| Modifications | Define whether buyers may edit configuration or resource files, and what support applies after changes |
| Team access | Clarify access for authorized staff, developers or contractors working for the customer |
| Redistribution and resale | Define restrictions on unauthorized sharing or resale where legally enforceable |
| Transfers | State how ownership changes and server migrations are handled |
| Third-party dependencies | Respect upstream licenses, asset rights and framework distribution requirements |
| Custom commissions | Use project-specific written terms when a custom development agreement differs |

## Important distinctions

- Repository **visibility** (private/public) does not by itself grant or revoke a license.
- Viewing a demonstration or documentation page does not grant access to paid code or artwork.
- Third-party components may have their own licenses, which must be respected.
- **No final entitlement, restriction or transfer policy has been approved by this draft.**

## Questions before purchase

Customers should confirm the specific product's license conditions and compatibility using the [official store](https://tonecustoms.tebex.store/) or [Discord support](https://discord.gg/JdZ7NTG5KF).

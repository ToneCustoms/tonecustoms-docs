# ToneCustoms Customer Journey

This page is the public map of where customers should go and what happens next.

| Stage | Customer destination | Expected outcome |
| --- | --- | --- |
| Discover | [Products](products/README.md) and [Features](FEATURES.md) | Compare documented script functionality and demos |
| Confirm availability | [Official Tebex](https://tonecustoms.tebex.store/) | Check current listing, price and checkout terms |
| Prepare | [Customer Checklist](CUSTOMER_CHECKLIST.md) and [Compatibility](COMPATIBILITY.md) | Understand requirements before installation |
| Install | [Installation Hub](INSTALLATION.md) | Find setup instructions and dependencies |
| Resolve a problem | [Troubleshooting](TROUBLESHOOTING.md) and [GitHub Support](SUPPORT.md) | Report an issue without exposing private information |
| Track support | [Notifications](NOTIFICATIONS.md) and [Support Dashboard](SUPPORT_DASHBOARD.md) | Understand assignment, status and GitHub notifications |
| Stay current | [Script Updates](SCRIPT_UPDATES.md) and [Announcements](ANNOUNCEMENTS.md) | Find verified changes and official news |
| Suggest improvements | [Feature Suggestions](https://github.com/ToneCustoms/tonecustoms-docs/issues/new?template=feature-request.yml) | Share ideas without a release guarantee |

## What ToneCustoms publishes

- **Official script releases:** Only after the actual release and delivery path are confirmed.
- **Version notes:** Script name, version, fixes, new features, compatibility and upgrade instructions.
- **Previews:** Clearly labeled Concept, In development or Preview.
- **Support:** Public GitHub issues for technical requests; private Tebex order threads for payment and order verification.
- **Notifications:** GitHub subscription controls ticket alerts; documentation updates are not automatically emailed to every customer.

## Quality and trust

Customer-facing links should resolve, pages should explain actual status, and documentation must never expose private code, license keys or personal customer data. The GitHub Pages workflow checks local links, restricted files and generated routes before publishing.

# About ToneCustoms

**ToneCustoms** is a FiveM development brand focused on creating custom resources and immersive experiences for roleplay servers.

Our approach is built around three priorities:

### Purposeful development

Resources should serve a clear gameplay or server-management purpose. Features are designed around how players and server owners actually interact with them.

### Clear documentation

Documentation should make it straightforward to understand what a resource does, what it requires, and how to configure it. Each resource will have its own information when it is ready to be documented.

### Continued improvement

Updates, refinements, and support information belong in one easy-to-find place, so server owners are not left searching through scattered messages.

## About this documentation site

This is the official information hub for ToneCustoms. It provides a central location for general information, announcements, common questions, and support guidance.

**Individual FiveM resources are not listed here yet.** Their dedicated pages will be introduced separately.

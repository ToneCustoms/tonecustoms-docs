## Which experience are you trying to add?

### More immersive weapon mechanics

Consider [Gun Jam](products/gun-jam.md) if you want firearm handling to involve additional gameplay decisions. Review its specific inventory dependencies and supported weapon configuration before purchasing.

[Watch the Gun Jam demonstration](https://youtu.be/kPniOo-VThw).

### More organized family roleplay

Consider [Family System](products/family-system.md) if your server needs player group management, ranks, and family-related features. Read its documented capabilities and confirm your server environment is supported.

### A hands-on civilian activity

Consider [Window Cleaning](products/window-cleaning.md) if you want an activity built around equipment, contracts and direct player interaction instead of only a timed progress indicator.

## Five questions to answer before purchasing

1. **Does it match the gameplay you want?** Read the actual product scope, not only a screenshot or video title.
2. **Does it support your server?** Check the framework and any required inventory, target, database, or library integrations.
3. **Can you install it?** Review the [installation information](INSTALLATION.md) and any product-specific setup instructions.
4. **Is it currently sold?** Confirm the listing and checkout terms on [Tebex](https://tonecustoms.tebex.store/).
5. **Do you need clarification?** Ask through [ToneCustoms Support](https://discord.gg/JdZ7NTG5KF) before purchasing.

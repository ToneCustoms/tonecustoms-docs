# Frequently Asked Questions

### What is ToneCustoms?

ToneCustoms develops custom resources and experiences for FiveM roleplay communities. Learn more on the [About](about.md) page.

### Where can I find resource documentation?

Individual resource documentation will be added to this site when it is ready. The current site contains only the general information sections.

### Which frameworks are supported?

Framework compatibility can vary by resource. Each future resource page will identify its supported frameworks and requirements rather than assuming every resource supports the same setup.

### Where will installation instructions be?

Installation steps, dependency lists, and configuration references will be provided in the relevant resource's documentation.

### How do I report an issue?

Read the [Support](support.md) page for the information to include in a clear support request.

### Where are announcements and changes posted?

Check [Updates](updates.md) for official documentation announcements and release information.

### Is this documentation public?

The documentation is intended for public access once the site owner publishes it. The GitBook website itself is not published yet.

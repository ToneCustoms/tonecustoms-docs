# Family System — Installation & Configuration

**Resource:** ToneCustoms Family System  
**Distribution:** Follow the delivery method shown on your Tebex order (the public listing describes Cfx.re Asset Escrow).

This is a **customer onboarding checklist**, not a substitute for the installation instructions included in the purchased package. The exact resource folder name and dependency list have not been confirmed in the public documentation.

## Setup checklist

1. Complete purchase through the [official ToneCustoms store](https://tonecustoms.tebex.store/).
2. Check your order confirmation, Cfx.re account linkage and entitlement instructions.
3. Obtain the authorized resource package through the specified delivery method.
4. Read its included installation and configuration files to confirm **the actual folder name**, framework integration, dependencies and any SQL instructions.
5. Install the required dependencies **in the order documented with the resource**.
6. Copy the authorized resource folder into the server resources directory and add its **actual** resource name to server startup configuration.
7. Edit designated configuration files only. Configure intended family ranks, permissions, HQ and garage options according to the delivered config.
8. Restart the affected resources and confirm access restrictions work for the intended users.

Do **not** assume that this resource uses Gun Jam's folder name, item definitions, dependencies, or controls.

## Verify expected behavior

- Family creation and member-management permissions
- Rank-based access and promotion restrictions
- Management interface accessibility
- Configured headquarters and vehicle/garage behavior
- Relevant client and server errors

## Support

If the resource fails to start, provide the first redacted console error, resource folder name, your framework and dependencies, and the steps already attempted through [ToneCustoms Discord](https://discord.gg/JdZ7NTG5KF). Never post Cfx credentials or protected source code.

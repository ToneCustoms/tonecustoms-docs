# Window Cleaning — Troubleshooting

| Problem | Diagnostic starting point |
| --- | --- |
| Job does not start | Required dependency startup, resource config, contract interaction and client errors |
| Vehicle or equipment does not appear | Supported resource options, permissions and configured spawn/interaction points |
| Cleaning minigame does not respond | Game focus/input conflicts, client errors, configured interaction and the supplied UI files |
| Window completion does not register | Follow the intended mouse-controlled interaction and examine relevant errors |
| Contract payout is missing | Verify completion requirements, server framework integration and server logs |
| Locations are unavailable | Check configured coordinates/contract locations and map compatibility |

Avoid editing protected code or guessing at configuration keys not provided by the purchased resource.

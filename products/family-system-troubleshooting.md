# Family System — Troubleshooting

Use this checklist with the **purchased package's actual installation instructions**. Framework names, SQL migrations and command or UI settings must be taken from the delivered build, not guessed.

| Symptom | Check first |
| --- | --- |
| Resource does not start | Actual resource folder name, fxmanifest, missing prerequisites and startup order |
| Management interface does not open | Configured permissions, framework/job integration, client console errors |
| Member management does not work | Family membership and rank restrictions, server-side error output |
| Ranks or promotions fail | Rank hierarchy, configured permissions and any required persistence |
| HQ/garage does not work | Configured locations, supported vehicles/garage integration and related errors |
| Changes are not saved | Required database connection/migrations **if specified by the delivered package** |

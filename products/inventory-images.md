# ToneCustoms Inventory Images

**Category:** Custom assets / inventory icons  
**Status:** Private custom asset development; quality review in progress  
**Distribution status:** Not listed as a public asset pack

## Overview

An internal collection of custom item artwork for FiveM inventories. The image library is stored in a **private repository**; this public page describes the quality standards only and does not expose, license, or distribute private images.

## Icon standard

| Attribute | Requirement |
| --- | --- |
| Final resolution | Exactly **100 × 100 px** |
| File format | PNG |
| Background | **Truly transparent**, with alpha channel |
| Object framing | Entire object visible and centered |
| Quality | No cropped parts, neighboring objects or background artifacts |
| Naming | Matching the target inventory item's image reference |
| Approval | Visual review and in-game confirmation before acceptance |

Current development focuses on creating complete, individual assets, **not cutting icons from a combined sprite sheet**. Images are not considered finished until reviewed.

## Compatibility

Intended for use with FiveM inventory item artwork, including **ox_inventory** image naming conventions. File placement depends on the consuming resource.

## Access

**Source art and unreleased icons are private.** For future product availability information, check [ToneCustoms Tebex](https://tonecustoms.tebex.store/) and [Discord](https://discord.gg/JdZ7NTG5KF).

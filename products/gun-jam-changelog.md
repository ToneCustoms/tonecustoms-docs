# ToneCustoms Gun Jam — Release History

This page records **publicly confirmed customer-facing releases** and links to their notes. A version number in a development repository, a planned fix, or a Cfx.re upload attempt is not evidence that a version was formally released to customers.

## Publication status

**Gun Jam is listed on the official ToneCustoms Tebex storefront.** The exact customer-facing version number and release date have not been independently confirmed for this public documentation page, so no release entries or dates are invented here.

## Current product behavior documented

These are **feature descriptions, not claims about which release introduced them**:

- Fixed 10-shot jamming cycle on supported firearms
- Per-weapon tracking with ox_inventory metadata
- Manual clearing with configurable input and animations
- Gun Cleaning Kit integration and weapon maintenance
- Support for configured firearms and compatible registered add-on weapons

## How release notes will be recorded

When a customer-facing update is formally released, document:

- The exact approved version identifier and publication date
- Added, changed, and fixed features
- Known limitations and compatibility changes
- Any required customer configuration or migration steps
- Where purchasers obtain the update

ToneCustoms provides released updates to purchased scripts without an extra update charge, subject to purchase terms. **No release schedule is guaranteed.**

# Free FiveM Resources

**ToneCustoms — Built for Roleplay. Made with Purpose.**

This page is the official directory for ToneCustoms resources intentionally published for **free public use**.

## Available free scripts

**No free script has been announced through this directory yet.**

ToneCustoms' other public repositories include documentation, project showcases and update metadata; they are **not automatically downloadable free FiveM scripts**. A video demonstration is not evidence that a resource has been publicly released.

When ToneCustoms approves a free release, this page will link directly to the official download repository, installation instructions, dependencies and licensing terms.

## Free release checklist

Before any script appears here, its public repository should have:

- A complete, approved downloadable FiveM resource (including `fxmanifest.lua` when applicable)
- Installation instructions and verified dependencies
- Configuration guidance and supported frameworks
- A clear license describing permitted use, redistribution and modification
- A changelog or release notes that reflect the actual released build
- No private credentials, paid source, licensed third-party assets, or sensitive internal files
- A confirmed release status approved by ToneCustoms

# Window Cleaning — Installation & Configuration

This is a **customer setup checklist** for ToneCustoms Window Cleaning. Exact dependencies, resource name and configuration keys must come from the delivered package.

## Install

1. Purchase through [ToneCustoms Tebex](https://tonecustoms.tebex.store/) and review your order's delivery instructions.
2. For the advertised Cfx.re Asset Escrow delivery method, ensure the entitlement is associated with the correct Cfx.re account.
3. Download and extract the authorized resource; locate its `fxmanifest.lua` and included setup instructions.
4. Confirm the required framework and dependencies in the delivered package. Start those resources first, in the documented order.
5. Add the **actual resource folder name** to your server startup configuration.
6. Configure the supported job locations, payouts, and other options using designated configuration files only.
7. Start the resource and review any client/server errors.

## Verify gameplay

- Job start/contract interaction
- Equipment pickup and vehicle workflow
- Travel to assigned cleaning location
- Mouse-controlled cleaning and completion
- Payout on successful contract completion

## Need assistance?

Provide the resource version if known, framework, relevant error messages, the point in the contract flow where the issue occurs and the steps already attempted.

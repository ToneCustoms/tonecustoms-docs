# Support

Need help with ToneCustoms? This page explains how to prepare a useful support request.

## Before requesting help

1. Check the [FAQ](faq.md) for common answers.
2. Review the relevant documentation if a resource-specific guide is available.
3. Note the exact issue and what you expected to happen.

## What to include

To help us understand the issue, provide:

- The resource name and version, if applicable.
- The framework and relevant dependencies.
- A short description of the problem.
- Relevant error messages or console logs.
- Steps that reproduce the issue.

**Do not share passwords, tokens, license keys, database credentials, or other secrets in a support request.**

## Where to contact ToneCustoms

Use the official ToneCustoms support channel associated with the resource or announcement. A direct support link will be added here once confirmed.

## Reporting a documentation issue

If a guide is confusing, incomplete, or outdated, specify the page and the section that needs attention.

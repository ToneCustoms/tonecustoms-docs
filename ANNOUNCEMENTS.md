## Announcement categories

- **New releases:** Newly published FiveM scripts, with the actual store listing and product documentation.
- **Script updates:** Verified customer-facing releases, version notes, migration instructions and fixes.
- **Development previews:** Work in progress, clearly marked as not yet released.
- **Community news:** Giveaways, showcases, videos, events and milestones once approved.
- **Support notices:** Temporary support changes or known service disruptions, with relevant dates.
- **Partnerships:** Confirmed collaborations and promotions approved for public announcement.

## Publishing a new announcement

Authorized maintainers can edit this page in the GitHub repository. Add the newest announcement at the top of the table and create a detailed section below when more context is needed. Use the [Announcement Publishing Guide](development/ANNOUNCEMENT_GUIDE.md) for the format and release-verification checklist.

**Do not label a script as released solely because a video, development commit or preview exists.** Confirm actual public availability and use the applicable product changelog for release details.

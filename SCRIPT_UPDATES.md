## What a script update entry must include

- **Script name and version:** identify the resource and the actual release version.
- **Release date and status:** published, not merely planned or demonstrated.
- **Added features:** new player or administrator functionality.
- **Changed behavior:** configuration, UI, compatibility or gameplay changes.
- **Fixes:** the specific problem resolved.
- **Upgrade instructions:** migrations, configuration changes, dependencies and whether a restart is needed.
- **Where to obtain it:** link to the official product delivery channel; do not distribute protected source here.

**No release has been invented for this page.** Product changelogs are the source for confirmed version details.

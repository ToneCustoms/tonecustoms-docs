# Contributing to ToneCustoms Documentation

Thanks for helping improve the **ToneCustoms** documentation community.

This repository is dedicated to public documentation and community information. Contributions should make information more accurate, easier to find, or easier to understand.

## Ways to Contribute

### Report a Documentation Problem

Open a [GitHub Issue](https://github.com/tonyiswavy/tonecustoms-docs/issues/new/choose) using **Documentation correction** if you find:

- Incorrect or outdated text.
- Broken links.
- Missing context or unclear instructions.
- Grammar or formatting mistakes.

Identify the page or section, explain the issue, and suggest a correction where possible.

### Suggest an Improvement

Use the **Documentation suggestion** issue template to recommend better organization, navigation, explanations, or accessibility.

For broader conversations, join [ToneCustoms Discussions](https://github.com/tonyiswavy/tonecustoms-docs/discussions).

### Propose a Change

If you want to submit a correction through a pull request:

1. Describe what you are changing and why.
2. Keep the proposed change focused on documentation.
3. Check links, spelling, and Markdown formatting.
4. Explain any significant removal or reorganization.
5. Use the repository's pull request template.

Maintainers review submissions and decide what gets merged. Proposing a change does not guarantee acceptance.

## Writing Standards

ToneCustoms documentation should be:

- **Clear:** easy to follow without unnecessary jargon.
- **Accurate:** do not invent features, release dates, support commitments, or compatibility claims.
- **Professional:** respectful, concise, and focused on the reader.
- **Consistent:** use the ToneCustoms name and link only to verified official channels.
- **Accessible:** use descriptive headings and link labels.

## Scope

This is **not a resource distribution repository**. Do not submit private source code, leaked content, paid files, license keys, credentials, or restricted assets.

This repository may document resources when the owner chooses to add that information; individual script uploads are not part of the contribution process.

## Conduct & Security

All contributions must follow the [ToneCustoms Community Guidelines](CODE_OF_CONDUCT.md).

If you notice a security concern, use the private reporting methods in [SECURITY.md](SECURITY.md) instead of posting sensitive information in an issue or discussion.

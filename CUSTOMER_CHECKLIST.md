# Customer Checklist — Before & After Your Purchase

**A practical guide for FiveM server owners considering a ToneCustoms resource.**

## Before you buy

- [ ] **Choose the right gameplay system.** Read the [Product Catalog](products/README.md) and its feature description.
- [ ] **Check current availability.** A demo or documentation page is not a store listing. Confirm the product is offered on [Tebex](https://tonecustoms.tebex.store/).
- [ ] **Check compatibility.** Review the product's framework, inventory, target, database, and other dependencies where documented. There is no universal framework guarantee.
- [ ] **Understand the scope.** Distinguish features currently included from features being developed or considered.
- [ ] **Review installation requirements.** Make sure your server setup can support the specific product.
- [ ] **Review purchase terms.** Read the [Customer Policy Center](policies/README.md) and actual checkout terms before ordering.
- [ ] **Ask questions first.** Use the [GitHub Support Center](https://github.com/ToneCustoms/tonecustoms-docs/issues/new/choose) if a required feature or dependency is unclear.

## After purchasing

- [ ] Follow the delivery and entitlement instructions for your **specific** Tebex order.
- [ ] Keep purchase details, keys, and access credentials private.
- [ ] Save an original copy of the delivered package in a secure location.
- [ ] Open the [Installation Hub](INSTALLATION.md) and the matching product-specific guide.
- [ ] Review the required dependencies and installation order.
- [ ] Add only the configuration, items, and database changes actually required by the product.
- [ ] Confirm the resource starts and its documented interactions function as intended.
- [ ] Save a backup of your allowed configuration changes.

## Before updating

- [ ] Confirm that the update is an **approved customer release**.
- [ ] Read the resource's release notes and migration instructions.
- [ ] Back up the current package, allowed configuration changes, and relevant data.
- [ ] Follow the [Update Guide](UPDATE_GUIDE.md) rather than blindly replacing every file.

## When requesting support

- [ ] Identify the product and version, if known.
- [ ] State the expected behavior and what happened instead.
- [ ] Include relevant framework/dependency information.
- [ ] Provide reproducible steps and **redacted** error messages.
- [ ] Use [GitHub Support](https://github.com/ToneCustoms/tonecustoms-docs/issues/new/choose) for product issues or the original private Tebex support channel for billing/order cases.

## What this checklist does not guarantee

This guide does not guarantee product compatibility, a fixed support response time, future updates, or custom development availability. The specific product documentation and the actual store checkout terms remain authoritative.

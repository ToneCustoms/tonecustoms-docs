## When resource guides are added

Future resource documentation will follow a consistent format:

- **Overview** — What the resource does.
- **Requirements** — Supported frameworks and dependencies.
- **Installation** — Setup steps in the correct order.
- **Configuration** — Options and intended behavior.
- **Troubleshooting** — Common issues and solutions.
- **Changelog** — Confirmed version changes.

These are documentation standards, not claims that any specific resource has been released.
